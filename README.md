# Говори српски — тренажёр

Карточки для повторения по учебнику **Јулија Шапић, «Говори српски да те цео свет разуме»** (Infotehnika, Београд, 2022).
Учебник одноязычный, поэтому русские переводы и ответы к упражнениям составлены для тренажёра.

Приложение: https://biralex.github.io/serbian-trainer/

## Что внутри

- **5873 карточки**: вводный урок, уроки 1–24 и грамматическое приложение;
- четыре колоды: **слова**, **фразы**, **грамматика** (правила и карточки «поставь в нужную форму»), **чтение** (азбука, тексты по предложениям, «Malo latinice», пословицы);
- письмо: кириллица, латиница или обе сразу; латиница вычисляется из кириллицы автоматически;
- режим «Тренировка»: сначала карточки на повторение, затем новые (по умолчанию 20 за раз, настраивается в меню «⋯»);
- направления «сербский → русский», «русский → сербский», вперемешку;
- интервальное повторение: «Не знаю» — через 5 минут, «Трудно» — через 12 часов, «Знаю» — 1, 3, 7, 14, 30, 90 дней;
- произношение через голос браузера (нужен сербский или хорватский голос на устройстве);
- установка как приложение (PWA) и работа без интернета после первого открытия.

## Прогресс

Прогресс хранится в браузере (`localStorage`, ключи `govoriSrpski.*`). Старые данные прежнего тренажёра (`serbianTrainer.*`) удаляются при первом запуске.

В меню «⋯» есть **«Сохранить прогресс в файл»** и **«Загрузить прогресс из файла»**: это резервная копия и способ перенести прогресс между телефоном и компьютером.

## Структура

```
index.html            интерфейс
styles.css            оформление
app.js                логика: отбор карточек, интервалы, письмо, экспорт/импорт
sw.js                 офлайн-кэш (при выпуске новой версии увеличить номер в CACHE)
data/meta.js          список уроков и функция addCards
data/lesson-NN.js     карточки урока NN
tools/validate.mjs    проверка карточек
tools/ids.lock.json   опубликованные ID карточек
```

## Как добавлять и исправлять карточки

Карточки описываются в `data/lesson-NN.js` вызовами `addCards(урок, колода, тип, раздел, страница, [...])`.
ID присваиваются автоматически по порядку внутри урока и колоды, а прогресс привязан к ID. Поэтому:

- новые карточки добавлять **только в конец** своей колоды в файле урока;
- не удалять карточки и не переставлять их. Ненужную карточку пометить `{ retired: true }`.

После правок запустить проверку:

```bash
node tools/validate.mjs
```

Она ловит дубли, пустые поля, русские буквы и смесь алфавитов в сербском тексте, а также «уехавшие» ID.
Когда проверка пройдена, новые ID записываются командой `node tools/validate.mjs --update`.
Если текст карточки исправлен (опечатка), используйте `--accept-changes`.

# Српски — тренажёр к уроку 1

Веб-приложение с карточками по уроку 1 книги В. В. Чарского «Сербский язык. Самоучитель».

## Что внутри

- 83 разговорные карточки: слова, выражения, фразы, вопросы, ответы и реплики диалога;
- 24 грамматические карточки;
- 30 карточек сербского алфавита;
- направления «сербский → русский», «русский → сербский» и смешанное;
- режимы новых, трудных, изученных и ожидающих повторения карточек;
- интервальное повторение и сохранение прогресса в браузере;
- произношение средствами браузера;
- работа без интернета после первого открытия.

## Запуск

Откройте `index.html` в браузере. Для публикации на GitHub Pages загрузите все файлы этой папки в корень репозитория и включите Pages для ветки `main`.

Произношение зависит от наличия сербского голоса на устройстве. Прогресс хранится локально и не синхронизируется между устройствами.
